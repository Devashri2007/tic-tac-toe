🎮 Tic-Tac-Toe — Challenge Your Mind!

Welcome to Tic-Tac-Toe, a fun and interactive game where strategy meets excitement! ✨ Play with your friends or challenge the AI to test your skills and aim for victory.

🌟 Game Modes

👥 2 Players Mode — Challenge your friends in a classic head-to-head battle.

🤖 Easy AI Mode — Practice your moves against a beginner-friendly computer opponent.

🧠 Unbeatable AI Mode — Take on a smart AI that uses strategy to make winning extremely difficult!

🚀 How to Play

1. Download or clone this repository.
2. Extract the ZIP file if you downloaded the project as a ZIP.
3. Open 'index.html' in your web browser.
4. Choose your game mode and start playing!
5. Get three of your symbols in a row, column, or diagonal to win. 🏆

🛠️ Technologies Used

- 🌐 HTML5 — Game structure
- 🎨 CSS3 — Styling and visual design
- ⚡ JavaScript — Game logic and AI opponent
